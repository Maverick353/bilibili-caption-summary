# B站字幕助手 · 实时字幕 + 逐字稿 + AI总结（含网课章节笔记）

一个**个人自用**的油猴（Tampermonkey）脚本：在 B站看视频时，**实时显示字幕** → 播放结束后拿到**完整逐字稿**并可复制/导出 → 直接调用大模型（默认 **DeepSeek**）生成总结。**支持「章节化笔记」模式，专为网课 / 讲座 / 系列教程设计。**

- 单文件、零依赖、无构建工具。
- 只针对 B站（`www.bilibili.com`）。数据仅在本机处理，API Key 仅保存在浏览器本地。
- 仅建议用于个人学习，请勿传播他人视频的逐字稿（版权）。

---

## 一、这是什么 / 能做什么

| 层级 | 能力 | 说明 |
| --- | --- | --- |
| **L1 实时字幕** | 播放中实时显示字幕浮层 | 抓取视频自带 CC / AI 字幕，叠加在视频上显示；可开关、可调字号、可拖动位置 |
| **L2 逐字稿** | 一键抓取完整逐字稿 | 支持复制全文，支持带 / 不带时间戳，支持导出 **SRT / VTT / TXT / JSON** |
| **L3 AI 总结** | 调用大模型生成总结 | 默认 **DeepSeek**，也支持 Kimi / 通义 / OpenAI；长视频自动分段（map-reduce）；**两种模式可选** |

### 两种总结模式

在「总结」标签的「**总结模式**」下拉框切换：

| 模式 | 适合 | 输出结构 |
| --- | --- | --- |
| **通用总结**（默认） | 普通视频、访谈、发布会 | 一句话概括 / 核心观点 / 内容脉络 / 关键结论与行动项 / 金句摘录 |
| **章节化笔记** | **网课、讲座、系列教程** | 课程标题 / 一句话总览 / **章节笔记（按章分节、逐条列知识点、带时间戳）** / 关键概念速览表 / 复习清单 |

「章节化笔记」输出示例：

```

### 第 2 章 · 章节标题（28:10）
- **知识点标题**：要点说明
## 关键概念速览
| 概念 | 说明 |
| --- | --- |
| xxx | xxx |
## 复习清单
- [ ] 需要掌握的点 1
```

## 二、安装步骤

1. **安装 Tampermonkey**：在 Chrome / Edge 的扩展商店搜索 `Tampermonkey`（篡改猴）并安装。
2. **新建脚本**：点击浏览器右上角 Tampermonkey 图标 → 「管理面板」→ 「+」新建脚本。
3. **粘贴代码**：打开本目录下的 `bilibili-caption-summary.user.js`，**全选复制**，覆盖编辑器里的默认内容。
4. **保存**：按 `Ctrl + S` 保存。
5. **打开视频**：访问任意 B站视频页（`https://www.bilibili.com/video/...`）或番剧页，右侧会出现「B站字幕助手」面板，脚本会自动尝试抓取字幕。

> 提示：如果面板没出现，刷新一次页面；个别页面可点击 Tampermonkey 图标 → 「显示/隐藏 面板」。
>
> **脚本更新后**：需按上面步骤 2-4 重新粘贴一次并保存；已打开的旧页面要**刷新**才会加载新代码。

## 三、获取 DeepSeek API Key

1. 打开 **platform.deepseek.com**，注册并登录。
2. 进入「API Keys」页面 → 「创建 API Key」→ 复制生成的 `sk-...`（**只显示一次，请及时保存**）。
3. 按量计费，**价格极低**（生成一次视频总结通常远低于 1 分钱）；新账号一般有赠送额度，如提示余额不足，充值几元即可用很久。
4. 回到 B站页面，打开脚本面板的「**设置**」标签：
   - API Base URL：`https://api.deepseek.com/v1`（默认已填好）
   - API Key：粘贴你的 `sk-...`（确认以 `sk-` 开头、前后无空格）
   - 模型：`deepseek-chat`（默认已填好）
   - 点击「**保存设置**」—— **这一步必须点，不点等于没填！**
   - 再点「**测试连接**」，显示「连接正常」即表示 Key / 余额 / 网络都可用。

## 四、使用步骤

1. **抓字幕**：打开视频页，面板「字幕」标签 → 多语言时在下拉框选择字幕轨 → 点「**抓取字幕**」。抓取成功后视频上会叠加实时字幕。
2. **看逐字稿**：切到「**逐字稿**」标签，可勾选是否「显示时间戳」，全文即完整逐字稿。
3. **导出**：在「逐字稿」标签点击 `导出 SRT / VTT / TXT / JSON`，或「复制全文」。
4. **生成总结**：切到「**总结**」标签 → 在「**总结模式**」下拉框选择 **通用总结** 或 **章节化笔记** → 点「**生成总结**」。长视频会自动分段并显示进度（如「正在整理第 2/5 段…」），完成后可「复制总结」或「导出 Markdown」（章节化笔记的导出文件名带 `_笔记` 后缀）。

> **播放结束自动处理**：视频播放到结束时，会弹出提示「播放结束，逐字稿已就绪」，提供「查看逐字稿」「生成总结」按钮；若在设置里勾选了「播放结束自动生成总结」且已填写 API Key，则会按当前选定的模式自动开始总结。

## 五、支持的导出格式

| 格式 | 说明 |
| --- | --- |
| **SRT** | 标准字幕文件，`00:00:01,000 --> 00:00:04,000`，可导入剪辑软件（剪映/Pr 等） |
| **VTT** | WebVTT，`00:00:01.000 --> 00:00:04.000`，网页播放器通用 |
| **TXT** | 纯文本逐字稿，可带 / 不带时间戳 |
| **JSON** | 结构化数据 `[{start, end, text}]`，便于二次处理 |
| **Markdown** | 「总结」标签导出，保存 AI 生成的总结（`.md`）；章节化笔记模式文件名带 `_笔记` 后缀 |

文件名规则：`{bvid或标题}_{语言}_{时间戳}.{后缀}`。

## 六、常见问题（FAQ）

**1）提示「没有可用的 CC/AI 字幕」怎么办？**
说明这个视频 up 主没有上传字幕、也没有开启 B站 AI 字幕，脚本没有可抓的字幕源。可改用「通义听悟」等在线工具，或本地 Whisper 方案（见第七节）。

**2）抓取时遇到 `-352` 风控 / 校验失败？**
脚本已内置**自动降级**：先尝试带 WBI 签名的接口，失败则退回不带签名的老接口。若两者都失败，通常是触发了风控。请确认：① 已登录 B站；② 刷新页面后重试；③ 稍等几分钟再试（避免高频请求）。

**3）提示未登录 / 拿不到签名密钥？**
请先在浏览器登录 B站账号（未登录时 `nav` 接口拿不到 WBI 密钥，字幕接口也可能不可用），然后刷新视频页。

**4）番剧 / 分 P 能用吗？**
支持。番剧页（`/bangumi/play/`）使用 `ep_id`；普通视频使用 `bvid` + `cid`，分 P 会根据 URL 的 `?p=` 自动选取对应 `cid`。站内切换视频 / 换集 / 换 P 后脚本会自动重新初始化。

**5）API Key 安全吗？**
Key 只保存在你本机浏览器（Tampermonkey 的 `GM_setValue` 存储），脚本**不会**把它写入日志或发送到除你配置的 API 地址以外的任何地方。请在个人设备上使用，不要分享含有 Key 的浏览器配置。

**6）B站改版后脚本失效怎么办？**
B站接口或页面结构变化可能导致失效。常见修复点：① 字幕列表接口路径（`/x/player/wbi/v2`）；② 页面元信息读取（`__INITIAL_STATE__`）。可在开发者工具 Network 面板确认实际接口，再相应调整脚本内的 URL 与字段名。

**7）字幕内容为 protobuf（`subtitle_urls`）时？**
脚本**优先**使用 JSON 格式的 `subtitle_url`；若某字幕轨只提供 protobuf 数组（`subtitle_urls`）而无 JSON，脚本会跳过并在界面提示不支持。

**8）提示「API Key 无效或已过期」怎么办？**
绝大多数是两种情况：① **Key 没有真正保存** —— 只填了输入框但没点「保存设置」；② 粘贴时**混入了空格或换行**。请到「设置」标签，**清空输入框**后重新粘贴（确认以 `sk-` 开头、前后无空白），**点「保存设置」**，再点「测试连接」验证。

**9）总结失败了，但看不到失败原因？**
现在**失败原因会一直显示在「总结」结果区**（不会像提示条那样消失）。脚本会按类型给出具体说明：`401/403` Key 无效、`402` 余额不足、`429` 请求过于频繁、请求超时、网络失败、模型返回为空。按提示处理即可。

**10）怎么快速判断是 Key 的问题还是网络的问题？**
点「设置」标签里的「**测试连接**」按钮。它会发一条极短的测试请求，并明确告诉你结果（成功会显示可用模型名，失败会显示具体原因）。

## 七、能力边界

- **仅支持 B站**。抖音、腾讯视频、爱奇艺等平台没有稳定可用的字幕接口，本脚本不覆盖。
- **只处理「字幕文本」，不处理画面**。脚本不具备语音识别（ASR）与图像识别能力，因此：
  - **没有字幕的视频**无法处理（需另走「音频捕获 + ASR」，例如本地 Whisper、通义听悟）；
  - 画面里的 **PPT、板书、公式、图表**不会被总结到（纯转写类工具的通病）；
  - 只有**硬字幕**（烧录在画面里）的视频同样无法抓取。
- **代码 / 公式密集型课程**的转写质量有限（把代码念成自然语言是常见问题），重要内容建议人工核对。
- 请遵守平台条款与版权规定，**仅在个人学习范围内使用，勿传播逐字稿**。

## 八、开发者信息（可选）

- 纯函数（共 **15 个**：`md5` / `getMixinKey` / `wbiSign` / `toSRT` / `toVTT` / `toTXT` / `toJSONText` / `formatTs` / `findCueIndexAt` / `chunkTranscript` / `buildSummaryPrompt` / `parseSubtitleBody` / `buildCourseNotePrompt` / `buildCourseNoteReducePrompt` / `buildCourseNoteMarkdown`）位于文件顶层作用域，可在 Node 下直接 `require()` 加载用于单元测试：

```js
const lib = require('./bilibili-caption-summary.user.js');
console.log(lib.md5('abc') === '900150983cd24fb0d6963f7d28e17f72'); // true
```

- WBI 签名所需 MD5 为**内联自实现**，不依赖 CDN / `crypto.subtle`，避免国内网络或 API 兼容问题。
- 单元测试：`node tests/qa-test.cjs`（共 143 个用例，零第三方依赖）。

### 实现要点（便于后续维护）

- 设置面板与字幕浮层用 **Shadow DOM 隔离**，避免与站点 CSS 冲突。
- 所有网络请求统一走 `request()` 封装（`GM_xmlhttpRequest`，跨域 + 带 Cookie）；调用外部大模型需在脚本头 `@connect` 声明目标域名。
- 用户内容一律用 `textContent` 渲染，**不拼 `innerHTML`**（防 XSS）。
- 设置项读取统一走内部函数 `readFieldValue(name)`（自动 `trim`），保证「保存设置」与「测试连接」口径一致。
